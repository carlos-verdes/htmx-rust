# htmx-rust

An open-source starter for server-rendered Rust web apps built with [htmx](https://htmx.org) and [maud](https://maud.lambda.xyz).

Planned scope:

- routing by page / section / subsection
- the URL as application state
- htmx glue
- layout and base components
- fast setup of new projects

**Status: early. The name is reserved; nothing is usable yet.**
